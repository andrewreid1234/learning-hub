# Jamieson Lab Learning Hub

Interactive, no-build learning resources for the software we use in the group. Plain HTML/CSS/JS: open `index.html` in a browser (or serve the folder), or use the single-file build in `dist/learning-hub.html`.

Courses: **AlphaFold3 on Woody** and **Boltz-2 on Woody**. Each has a Windows / Mac / Linux switch for the parts that run on your own computer.

## Layout
- `index.html`: shell and styles. `hub.js`: the course engine (`Hub.register`, `Hub.widget`).
- `courses/<name>.js`: course content as data. `courses/<name>-widgets.js`: interactive widgets.
- `courses/real-examples.js`: real AF3 confidence data, generated by `tools/extract_examples.py`.
- `tools/bundle.py` writes the single-file `dist/learning-hub.html`. `tools/selftest.html` + `tools/serve_test.py` are the headless browser tests.

## Adding a course
Create `courses/<name>.js` calling `Hub.register({...})`, add its `<script>` tag between the `COURSES` markers in `index.html`, then run `python3 tools/bundle.py`.

Paths such as `/scratch/drewdog/boltz` and `/data/20260825_AndrewR_af3` are specific to the group's Woody server.
